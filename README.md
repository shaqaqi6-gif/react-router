# نظام تدقيق نقليات الدريس — نموذج التكلفة الواجبة

منصّة تدقيق فواتير نقليات توريد أرامكو: تحوّل الفواتير الشهرية (Excel) إلى تحليل
«الهدر» (محطات وُرّدت من مركز أبعد من الأقرب)، مع لوحات تحكم، خرائط مسارات،
كشف شذوذ، كفاءة حمولة، وتقرير رسمي بالتوصيات.

> أُعيدت هيكلة المشروع من ملف `index.html` واحد بحجم ~3 ميجابايت إلى مشروع
> [Vite](https://vitejs.dev/) منظّم وقابل للصيانة، مع تحميل مكتبتي
> Leaflet و SheetJS من npm بدل تضمينهما.

## التشغيل

```bash
npm install      # تثبيت المكتبات
npm run dev      # خادم تطوير محلي (إعادة تحميل فوري)
npm run build    # بناء للإنتاج → مجلد dist/
npm run preview  # معاينة ناتج البناء محليًا
```

## البنية

```
.
├── index.html          # هيكل الصفحة (login + topbar) ونقطة دخول Vite
├── vite.config.js      # إعداد البناء
├── netlify.toml        # أمر البناء + ترويسات الأمان لـ Netlify
├── public/
│   ├── favicon.svg
│   └── _redirects      # توجيه SPA على Netlify
└── src/
    ├── main.js         # منطق الواجهة: التنقل، العرض، الخريطة، رفع الفواتير، خطة العمل
    ├── engine.js       # محرّك التدقيق (runAudit): الفواتير الخام → AGG/STATIONS/GEO
    ├── data.js         # البيانات الأوّلية والمراجع الثابتة (GEO/CENTERS/RM/REF)
    └── styles/
        └── app.css     # تنسيقات التطبيق (تنسيقات Leaflet تأتي من npm)
```

### تدفّق البيانات

1. `engine.js` يصدّر `AldreesAudit.runAudit(rows, REF, period)` ويعيد `{ AGG, STATIONS, GEO_trips }`.
2. `data.js` يوفّر القيم الأوّلية (`initialAGG`, `initialStations`) والمراجع الثابتة.
3. `main.js` يربط الواجهة؛ وعند رفع فاتورة جديدة يستدعي `runAudit` ويحدّث الحالة عبر `applyAudit`.

## ملاحظات أمنية مهمّة

تسجيل الدخول الحالي **تحقّق من جهة العميل فقط** (مقارنة هاش في المتصفح)، وهو
غير كافٍ لحماية بيانات حسّاسة. يُنصح بشدّة بترقيته إلى مصادقة من خادم
(مثل Netlify Identity / Auth0) كخطوة تالية قبل النشر الإنتاجي.

## سجل الإصدارات

- **1.2.0** — إصلاح ربط مركز «أرامكو بيش» (كان يظهر ضمن جازان)، قراءة أسرع للفواتير (ورقة واحدة بوضع dense)، اكتشاف الشهر تلقائياً من اسم الملف، مبدّل للتنقّل بين الفواتير المرفوعة (يحدّث كل الصفحات)، وتصدير تقرير أي فترة من المقارنة الشهرية.
- **1.1.0** — صفحة «خطة العمل حسب الفترات» (خطة معالجة مرحلية بأثر مالي + مسار أداء عبر الأشهر)، أيقونات SVG احترافية بدل الإيموجي، تحسين الخطوط ومعالجة تداخل العناوين، تفاعلات وانتقالات للواجهة، وإظهار رقم الإصدار.
- **1.0.0** — إعادة هيكلة الموقع من ملف واحد إلى مشروع Vite منظّم.

## النشر

البناء مهيّأ لـ Netlify (`netlify.toml`): الأمر `npm run build` والنشر من `dist/`.
