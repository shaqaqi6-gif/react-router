# لا تظهر الاعتمادات لمساعد الإشراف — التشخيص والإصلاح (V8.2.3)

## لماذا لا أستطيع الجزم بالسبب من هنا

صلاحيات مساعد الإشراف تُقرأ من شيت `ROLE_PERMISSIONS` الذي يزرعه `seedRolePermissions_` في **`Admin.gs`** — وهو الملف الوحيد الذي لم يصلني بعد. لذلك بدل التخمين، أضفت أداة تُخرج السبب الدقيق من بياناتك أنت.

## الخطوة الأولى: شغّل التشخيص

في محرر Apps Script، اختر الدالة `DIAGNOSE_APPROVALS` واضغط تشغيل — أو من نافذة التنفيذ:

```js
DIAGNOSE_APPROVALS('رقم كمبيوتر مساعد الإشراف')
```

ثم افتح **السجل (Executions / Logs)** وأرسل لي المُخرَج. سيطبع:

```
المستخدم: { الدور، النطاق، المناطق، مديره، معتمِده }
الصلاحيات_المؤثرة: { VISIT_APPROVE, VISIT_VIEW_ALL, VISIT_VIEW_SCOPE }
يظهر_له_قسم_الاعتمادات: true/false
الزيارات: [ { رقم_الزيارة، نفّذها، مُسندة_إلى، المنطقة، يستطيع_اعتمادها، السبب } ]
```

حقل **`السبب`** يذكر الحاجز بالنص لكل زيارة على حدة.

## الأسباب الخمسة الممكنة — وأيها الأرجح

بحسب ترتيب الفحص في `canApproveVisit_`:

| # | الحاجز | العلاج |
|---|---|---|
| ١ | **لا يملك `VISIT_APPROVE`** | لن يظهر له قسم «الاعتمادات» في القائمة أصلًا. امنح الصلاحية لدوره من شاشة الصلاحيات. **هذا الأرجح.** |
| ٢ | الزيارة **مُسندة إلى شخص آخر** (مثلًا 11007) وهو ليس مديره ولا يملك `VISIT_VIEW_ALL` | استخدم زر **«إعادة الإسناد»** الجديد |
| ٣ | الزيارة **خارج نطاقه** — نطاقه `REGIONS` ومنطقة الزيارة لا تطابق مناطقه | صحّح مناطقه، أو اجعل نطاقه `ALL` |
| ٤ | **عمود المنطقة فارغ** في سجل الزيارة ونطاقه `REGIONS` | لا تطابق أي منطقة فيُحجب. صحّح المنطقة في سجل المحطة |
| ٥ | هو **منفّذ الزيارة** | لا أحد يعتمد زيارته — بحق |

السببان ٣ و٤ خفيّان لأن الزيارة لا تظهر ولا يظهر سبب، ولهذا يذكرهما التشخيص صراحة.

## الخطوة الثانية: فكّ العالق فورًا

أضفت زر **«إعادة الإسناد»** في صفحة الاعتمادات، على كل صف لا تستطيع بتّه (لمن يملك `VISIT_PLAN_MANAGE`). يفتح قائمة بكل من يملك فعلًا صلاحية الاعتماد — ويرفض الإسناد إلى منفّذ الزيارة أو إلى من لا يملك `VISIT_APPROVE`، مع ذكر السبب. كل نقل يُسجَّل في `AUDIT_LOG` ويصل المعتمِد الجديد إشعار.

إن كانت القائمة فارغة فهذا بنفسه هو الجواب: **لا يوجد في النظام مستخدم آخر يملك صلاحية الاعتماد**.

## التحقق
- ٩ اختبارات وحدة لكشف السبب، تغطي الحواجز الخمسة والحالات المسموحة.
- اختبار متصفح لدورة إعادة الإسناد كاملة: ظهور الزر، قائمة المرشحين مع تمييز الحالي، التنفيذ، وإغلاق النافذة.
- بلا تراجع: ٣٦ اختبار قواعد الزيارة، ٩ اختبارات الإسناد، صفحة الاعتمادات، القائمة الجانبية، وثمانية عروض شاشة.
